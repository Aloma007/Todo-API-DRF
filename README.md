😇 Todo List API (Django REST Framework)

This is a production-ready backend API for managing a to-do list, built with Python, Django, and Django REST Framework. 

## Features
* Custom User Authentication using JWT (JSON Web Tokens)
* Secure Login and Refresh Token endpoints
* CRUD operations for Tasks tied to specific authenticated users
* Dynamic Search and Sorting filters
* Database Pagination
* Global Rate Limiting and API Throttling
* Automated Unit Testing suite

This project is my solution to the [roadmap.sh Todo List API project](https://roadmap.sh/projects/todo-list-api).
